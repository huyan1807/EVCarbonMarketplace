EVCarbonMarketplace
EVCarbonMarketplace is a cloud-based platform built with .NET 8, designed to facilitate the trading and management of carbon credits for electric vehicle (EV) stakeholders. The system provides secure, scalable APIs for user management, carbon credit transactions, and reporting, supporting sustainability initiatives and regulatory compliance.
Key Features
•	Modern Backend: Developed with ASP.NET Core 8.0, following clean architecture principles.
•	Database: Utilizes Microsoft SQL Server for primary data storage and Redis for caching.
•	Authentication: Secure OAuth 2.0 integration with Google and role-based authorization.
•	Third-party Integrations: Supports Cloudinary (media), PayOS (payments), Google Analytics, Firebase (cloud storage), and SMTP (email notifications).
•	Performance & Scalability: Implements caching, asynchronous processing, and stateless API design for high performance and easy scaling.
•	Deployment: Cloud-ready with environment-based configuration and secure secrets management.
