# EVCarbonMarketplace

Cloud-based carbon credit trading platform for EV stakeholders, built with ASP.NET Core .NET 8 and modern cloud-native architecture.

---

## 📌 Business Purpose

EVCarbonMarketplace is designed to facilitate the trading and management of carbon credits for electric vehicle (EV) stakeholders.  
The platform enables users to securely buy, sell, and track carbon credits while supporting sustainability initiatives and regulatory compliance.

---

# 🚀 Features

- Secure carbon credit trading platform
- JWT Authentication & Role-Based Authorization
- Google OAuth 2.0 Login
- RESTful API Architecture
- Redis Caching for performance optimization
- API Gateway using Ocelot
- Cloudinary media management
- PayOS payment integration
- Firebase integration for notifications/storage
- Swagger/OpenAPI documentation
- Scalable cloud-ready deployment
